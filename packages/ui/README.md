# `@dnam-project/ui` — DNAM Unified Design System

Shared React 19, Tailwind CSS v4 (`@tailwindcss/vite`), `shadcn/ui`, and `lucide-react` design system for the **Dynamic Neural Audio Modeler (DNAM / "Tri-Physics")** Tauri v2 Desktop Studio (`packages/studio`) and Astro/Starlight Web Studio (`packages/web`).

## Exports

- `@dnam-project/ui` — Full component, visualizer, token, and `DnamAudioHost` exports.
- `@dnam-project/ui/styles.css` — Shared Tailwind CSS v4 `@theme` and Starlight stylesheet.
- `@dnam-project/ui/tokens` — Design token constants and color/typography descriptors.
- `@dnam-project/ui/host` — `DnamAudioHost`, `<DnamAudioHostProvider>`, `useDnamAudioHost`, and `WebAudioWorkletHost`.
- `@dnam-project/ui/visualizers` — Interactive Tri-Physics mathematical and DSP visualizers.
